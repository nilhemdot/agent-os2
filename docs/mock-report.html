What this report does and does not cover

This report flags known risky patterns in the files that configure AI coding agents (agent settings, MCP server definitions, instruction files and tasks), using fixed rules, offline. It does not read your application source code, dependencies or build scripts, and it does not show that a repository is free of problems. Each finding is dated to the first-parent commit at which it appeared; commits that arrived through a merge are attributed to the merge, a renamed file starts a new finding, and a shallow or truncated history only gives 'on or before' dates. Monthly counts are computed by scanning the repository as it was at the end of each month with today's rules, so a rule added recently also counts findings from earlier months. Suppressions and size limits are read from the current version of the repository's configuration unless --no-repo-config is used.
